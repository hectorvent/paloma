# Planned commands

All commands currently exposed by `paloma --help` are implemented. The receive-side
`webhook listen`, `verify-url` and `simulate` tools now ship; see
[webhook](webhook.md) for setup and local testing.

The template lifecycle and advanced management tools are implemented; see
[template](template.md) and [send template](send.md#paloma-send-template).

The v1.5 number identity/settings, commerce, account administration and Flow tools
are implemented; see their command pages. Full 24-hour window tracking remains future
work.
